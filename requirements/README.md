# Requirements Documentation (`requirements/`)

This directory contains the complete Software Requirements Specification (SRS) for the **Online Examination System**.

## Directory Contents
- [`requirements_document.md`](file:///Users/sandeshchaudhary/Desktop/Testing/requirements/requirements_document.md): Full SRS document outlining system vision, user roles, functional specifications, non-functional constraints, and user stories.

## Overview of Requirements Engineering
Requirements were gathered using a combination of user interviews with academic instructors, student feedback surveys, and benchmark analysis of commercial online testing platforms (such as Canvas, Moodle, and Google Forms).

Key focus areas include:
1. **Security & Integrity**: Prevention of unauthorized access and tab switching during exams.
2. **Usability & Performance**: Intuitive exam interface with low latency autosaving.
3. **Automated Analytics**: Detailed score breakdowns and performance metrics for instructors.
